Windows setup

Windows 10 or 11, 64-bit. No administrator rights, no driver. About two minutes. version 2.2.1 · preview

Preview. On Windows the Tap runs, starts at sign-in, answers the web app, and handles test tones, AES67 / SAP discovery and PTP. It does not yet meter the PC's own sound. See what to expect.

Install

  1. Download and unzip

    Download ward-beck-audio-tap-windows.zip. In Downloads, right-click it › Extract All… › Extract.

  2. Run the installer

    Right-click install.ps1 › Run with PowerShell. On Windows 11 it is under Show more options. A blue PowerShell window opens.

    If Windows asks "Do you want to run this file?" or shows "Windows protected your PC", choose More info › Run anyway. That appears because 2.2.1 is not yet code-signed.

  3. Allow the network

    The first time the Tap starts, Windows Defender Firewall may ask about ward-beck-audio-tab. Tick Private networks and press Allow. SAP, PTP and AES67 use multicast and need this; the meters on this PC work either way.

  4. Read the result

    The window finishes with three OK lines. The last one gives the version and says the Tap answers.

  5. Open the web app

    Go to ward-beck.ca or xtm.wbsps.ca. If the browser asks to let the site reach devices on your local network, allow it: that is the Tap on this PC.

What you will see

WhereExpect
DesktopNo window and no tray icon. The Tap runs hidden from Task Scheduler.
Task Managerward-beck-audio-tab.exe, a few MB of memory, under 1% CPU when idle.
After a restartIt starts on its own when you sign in. If it ever stops, Windows restarts it within a minute.
Web appConnects; test tones, AES67 / SAP stream lists and PTP clocks fill in. Meters of the PC's own sound stay silent in 2.2.1.
Timing tabPTP over UDP is heard. gPTP (raw Ethernet) is not, and the card says so.
LogERROR [cmd] 'pactl' is not installed and similar lines for other Linux tools. Normal: those features are Linux-only.

Update

Download the new zip, extract it, and run its install.ps1 the same way. It stops the running copy, replaces it and starts the new one. Logs are kept.

Remove

Right-click uninstall.ps1 (in the download, or in %LOCALAPPDATA%\Ward-Beck\Audio Tap) › Run with PowerShell. It removes the start-up task and the program and keeps the logs folder; delete that folder by hand if you want it gone.

If something is wrong

You seeDo this
The PowerShell window flashes and closesOpen PowerShell, cd to the extracted folder, and run powershell -ExecutionPolicy Bypass -File install.ps1 so the message stays on screen.
!! The Tap did not answer yetWait ten seconds, then open 127.0.0.1:8467/api/diagnostics. Still nothing: send tap.log.
Port 8467 already in useAnother copy is running. Run install.ps1 again; it stops the old one first.
Web app says no TapCheck 127.0.0.1:8467/api/diagnostics opens in the same browser, and allow local network access if the browser asked.
No streams or PTP clocks from the networkThe firewall prompt was dismissed. Windows Security › Firewall & network protection › Allow an app through firewall › tick ward-beck-audio-tab for Private. Check the network is set to Private, not Public.

For any report, send the file from 127.0.0.1:8467/api/diagnostics/bundle (see If something is wrong).
