macOS setup

macOS 14.2 (Sonoma) or newer, Apple silicon or Intel: one download for both. No administrator password, no driver. About two minutes. version 2.2.1 · preview

Preview. On macOS the Tap runs, starts at login, answers the web app, and handles test tones, AES67 / SAP discovery and PTP. It does not yet meter the Mac's own sound. When that arrives, macOS will ask once for permission to record system audio. See what to expect.

Install

  1. Download and unzip

    Download ward-beck-audio-tap-macos.zip. Safari usually unzips it for you; otherwise double-click it in Downloads. You get a folder ward-beck-audio-tap-macos.

  2. Run the installer in Terminal

    Open Terminal (Spotlight: ⌘ Space, type Terminal, Return). Type bash and a space, drag install.sh from the Finder window into Terminal, then press Return. Or type it out:

    cd ~/Downloads/ward-beck-audio-tap-macos
bash install.sh

    Don't double-click install.sh in Finder; it opens in a text editor and does nothing. The installer clears the download quarantine itself, so Gatekeeper won't block the Tap even though 2.2.1 is not yet signed.

  3. Read the result

  4. Allow the network

    macOS may ask whether ward-beck-audio-tab may find and connect to devices on your local network, or (with the firewall on) accept incoming connections. Press Allow. SAP, PTP and AES67 use multicast and need it; the meters on this Mac work either way.

  5. Open the web app

    Go to ward-beck.ca or xtm.wbsps.ca. If the browser asks to let the site reach devices on your local network, allow it: that is the Tap on this Mac.

Update

Download and unzip the new version and run its bash install.sh. It stops the running copy, replaces it and starts the new one. Logs are kept.

Remove

bash ~/Downloads/ward-beck-audio-tap-macos/uninstall.sh

It stops the Tap, removes the LaunchAgent and the program, and keeps ~/Library/Logs/Ward-Beck Audio Tap; delete that folder by hand if you want it gone.

If something is wrong

You seeDo this
⚠ The Tap did not answer yetAnswer any permission prompt, wait ten seconds, open 127.0.0.1:8467/api/diagnostics. Still nothing: send tap.log and tap.log.stderr from the log folder.
"cannot be opened because the developer cannot be verified"You started the program by double-clicking it. Use bash install.sh instead; it clears that block.
Bootstrap failed: 5: Input/output errorAn old copy is still loaded. Run bash uninstall.sh, then bash install.sh.
Older than macOS 14.2The Tap needs 14.2 or newer (Apple menu › About This Mac).
No streams or PTP clocks from the networkThe network prompt was refused. System Settings › Privacy & Security › Local Network › turn on ward-beck-audio-tab.
Web app says no TapCheck 127.0.0.1:8467/api/diagnostics opens in the same browser, and allow local network access if the browser asked.

For any report, send the file from 127.0.0.1:8467/api/diagnostics/bundle (see If something is wrong).
